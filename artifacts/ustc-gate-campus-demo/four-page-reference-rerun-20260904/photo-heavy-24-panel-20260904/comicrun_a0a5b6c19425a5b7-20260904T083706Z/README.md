# Photo-heavy 24-panel sample

This published sample contains rendered outputs from a four-page, 24-panel
photo-reference comic experiment:

- `page-*.jpg`: four composed six-panel pages covering all 24 generated panels.
- `chapter-overview.jpg`: complete chapter contact sheet.

Input reference images, prompts, request and result metadata, and machine-local
paths are intentionally excluded from version control.

The published JPEG previews preserve the complete visual sample while keeping
the repository lightweight. Individual panel previews and lossless PNG outputs
remain local.
